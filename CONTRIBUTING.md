# Как внести вклад

Спасибо, что помогаете сделать список лучше! 🇰🇿

## Что можно добавлять

- Реальные, работающие ресурсы для IT-специалистов в Казахстане.
- Компании, школы, гранты, комьюнити, API, датасеты, инструменты.
- Только живые ссылки — проверьте, что они открываются.

## Правила оформления

1. **Один PR = одно логичное изменение** (например, «добавил 3 датасета»).
2. Формат записи:
   ```
   - [Название](https://ссылка) — короткое описание на русском (одно предложение).
   ```
3. Описание — по делу, без рекламы и превосходных степеней без причины.
4. Держите алфавитный/логический порядок внутри раздела, где это уместно.
5. Ставьте запись в правильную категорию. Нет подходящей? Предложите новую в PR.

## Чего избегать

- ❌ Реферальных ссылок и партнёрских меток.
- ❌ Мёртвых ссылок и заброшенных проектов.
- ❌ Дубликатов — проверьте, нет ли ресурса в списке.
- ❌ Чисто рекламных записей без реальной пользы для сообщества.

## Как отправить PR

1. Сделайте fork репозитория.
2. Создайте ветку: `git checkout -b add-resource`.
3. Внесите правку в `README.md`.
4. Коммит: `git commit -m "Add: <название ресурса>"`.
5. Push и откройте Pull Request с кратким описанием.

## Telegram-чаты и протухающие ссылки

Ссылки на TG-чаты часто становятся неактивными. Добавляйте только те, которые **лично проверили** и которые действительно живые на момент PR.

Спасибо! ⭐
